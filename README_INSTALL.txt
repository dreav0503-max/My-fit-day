MY FIT DAY - INSTALLABLE PWA

These files are ready to host as a Progressive Web App (PWA).

Files to upload together:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- .nojekyll (for GitHub Pages)

After the site is hosted over HTTPS, open its web address in Chrome on Android.
Then either tap the in-app "Install app" button if it appears, or use Chrome's menu and choose "Install app" / "Add to Home screen".

Your logged data is stored locally in the browser on that device. Clearing site data or uninstalling may remove it, so this version does not yet include cloud backup/sync.
